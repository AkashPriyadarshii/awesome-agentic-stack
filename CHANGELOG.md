## [1.0.0] — 2026-05-29

### Added
- **Core Repository Scaffolding**: Initial structure for our curated ₹0 agentic coding awesome stack.
- **Workflow Phase Setup**: README.md organized by workflow-session order (Phases 0–4).
- **Comprehensive WORKFLOW.md**: Terse, high-density instructions detailing cross-device session setup (Mac M5 + GT7).
- **Contributing & Quality Gate Policy**: CONTRIBUTING.md defining strict audit rules (₹0, recent commits, non-overlapping functionality).
- **Rejected & Watching Trackers**: `lists/rejected.md` and `lists/watching.md` established.
- **Automated Link Check**: GitHub Actions workflow at `validate_links.yml` for monthly URL health.
